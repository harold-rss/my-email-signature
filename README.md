# My Email Signature

HTML email signature for **rocket science solutions**, hosted on GitHub Pages.

## Live preview

https://harold-rss.github.io/my-email-signature/

## Files

| File | Purpose |
|------|---------|
| `index.html` | The signature (inline styles, table layout for email-client compatibility) |
| `logo.png` | Company logo, served from GitHub Pages |

## How to use

1. Open the live preview link above in your browser.
2. Select the whole signature (Ctrl+A) and copy it (Ctrl+C).
3. Paste it into your email client's signature settings (e.g. Spacemail → Settings → Signature).

## Editing

- Edit `index.html`; keep styles inline so email clients render them.
- The logo is loaded from the GitHub Pages URL, so changes go live after pushing to the published branch.
- Accent line colour: `#0078A2`.
